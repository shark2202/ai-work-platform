# 服务清单（实测，非规划）

本机所有对外监听的服务，分两层：**环境/外壳层**（agent 在哪跑、怎么远程看终端）与
**产品层**（短剧产线本身）。

## 环境 / 外壳层（不是短剧产品的一部分）

| 服务 | 监听 | 鉴权 | 干什么 |
|---|---|---|---|
| `herdr.service` | unix socket | 本地 | 终端工作区/面板管理器（headless 守护进程），pi 的 pane 都挂在它下面 |
| `herdr-web.service` | **0.0.0.0:8787** | **无**（服务注释里明说） | herdr 的浏览器 UI：看面板、开终端 |
| `code-server` | 0.0.0.0:8888 | 自带配置 | 通用 IDE 入口 |
| `mochi` 插件 | — | — | 把 agent 状态推到 iPhone（herdr 事件钩子） |

## 产品层（短剧 / 短视频产线）

| 服务 | 监听 | 鉴权 | 干什么 |
|---|---|---|---|
| **审片台**（shortdrama `sd studio`） | 0.0.0.0:8095 | 读开放 / 写要令牌 | 看板 · 审片 · 放映 · 交付审批（systemd user 常驻） |
| **ComfyUI** | 0.0.0.0:8188 | 无（C7） | 渲染体：Z-Image 出图 / MiniMax-H3 出镜 |
| **本地 27B** | 0.0.0.0:8080 | 无 | 剧本 / 台词 / 逻辑体检（与渲染互斥） |
| **job 目录** | 文件 | 文件权限 | 唯一真相源（不是服务，是状态） |

## 暴露面结论

**三个 0.0.0.0 且无鉴权的服务**：`8787`（能开终端 = 拿到 shell）> `8188`（能提交渲染、读所有人的 output）
> `8080`（能白嫖模型算力）。**唯一做了权限分级的是我们自己的审片台**（读开放、写要令牌）。

生产建议：
1. `herdr-web` 绑 tailscale（`100.69.133.37`）或加反代鉴权 —— 它比 ComfyUI 风险更高；
2. ComfyUI 与 LLM 绑回环，只在需要时用 SSH 隧道；
3. 审片台保持 `0.0.0.0`（审片就是要手机能看），写操作必须带令牌。

清单数据在 `platform.lock.json` 的 `runtime_layer` / `exposure_audit` 两段；
体检脚本 `ops/healthcheck.sh` 会一起检查这些端口。
