## 出事了先查什么

```bash
bash ops/healthcheck.sh          # 三件套 + GPU
journalctl --user -u shortdrama-studio.service -n 50   # 审片台日志
tail -3 /home/a/ai-work/duanju/*/logs/run.log           # 渲染心跳
nvidia-smi --query-compute-apps=pid,used_memory --format=csv   # 谁占着显存
```

## 三个高频坑

1. **显存被 LLM 占住** → 渲染/超分起不来（单卡 22GB，C2）。`superres.py` 会等显存 < 4000 MiB；
   渲染前要确认 `nvidia-smi` 里没有 19GB 的 llama 进程。
2. **成片比 clip 旧** → 重压过 clip 没重跑后期。`assemble` 会复用 `clips/upscaled*.mp4`（按 mtime 判断），
   clip 变了它会自动重做，但**审批状态**会因此自动回落（这是有意的）。
3. **字幕看不见** → 竖屏用 ffmpeg `subtitles=` 滤镜时 libass 会按默认 `PlayResY=288` 缩放 MarginV
   → 字幕被推出画面。必须用**自写 ASS**（`PlayRes = 交付分辨率`），见 `episode.py` 的 `build_ass`。
